# /jury learnings

Dated corrections, newest last. Format: Rule / Why / Before → After. Append one whenever the user corrects a jury run.

Two seed rules ship with the template; they came from the jury's first real runs.

- Seed. Rule: every price or number in the Step 0 brief is read from the live source at framing time, never copied from a context note. Why: a brief once carried a stale price from an older context line; the fact-checker caught it before a juror voted on it. Before: facts gathered from context notes. After: Step 0 opens the live source for every customer-facing number and cites it as `[live, <url>, <date>]`. The fact-checker seat stays mandatory because it caught the slip.
- Seed. Rule: the closing test checks the jury's verdict. It is never a new product idea taken from the dissent seat, and it never makes the user do manual fulfilment work. Why: a run once closed on the dissenter's own giveaway idea, which tested a different hypothesis and cost the user hours. Before: the adjudicator adopted the dissenter's test. After: the dissent can change the verdict or its reasons, but the test is chosen against the final verdict, and the user's own effort in it is at most one message or one look at a number.
