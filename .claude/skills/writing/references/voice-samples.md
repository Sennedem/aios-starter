# Voice samples

The user's real writing. The `writing` skill reads this file in Step 0 and matches its sentence length, word choice, punctuation, openings, transitions and sign-offs. These samples and `learnings.md` outrank every other file in this skill. If the samples use dashes, drafts may use them at about the same rate.

## How to fill it

- Paste 3 to 5 pieces the user actually wrote and sent or published: emails, messages, posts, a section of a report.
- Paste them unedited, typos and all. Do not clean them up.
- Use real past writing only, never a piece typed fresh for this file. A freshly typed sample shows how someone writes when they know they are being studied, and that is the voice to avoid copying.
- Mix formats where possible, and label each sample with its format and audience.
- The `setup` skill fills this file the first time. The user can add or replace samples at any time.

While this file holds no samples, the skill writes neutral and direct.
