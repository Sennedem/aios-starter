# Other worlds

The brain holds markdown. Everything else lives where it belongs: code in its repository, media and office files in a cloud folder, a site on its host. Each of those places gets one short routing note here, so Claude knows where to look and how to work there.

To add one, copy `_template.md` to `<name>.md` and fill it in, or tell Claude "this project lives in <place>" and it writes the note.
