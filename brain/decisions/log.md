# Decision log

Append-only. Every real decision gets an entry with its why, so that six months from now you and Claude can both see what was known at the time. Newest at the bottom. Entries are never edited, a reversal is a new entry that links back.

Entry format:

```
## YYYY-MM-DD: <the decision in one line>
- Context: what forced the choice
- Options considered: A, B, C
- Decided: which one
- Why: the reasoning, including what would change the call
- Check: the cheapest test that would show this was wrong
```
