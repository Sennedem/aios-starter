# The baseline and outlier spreadsheet

From the [[wiki/sources/vidiq-youtube-algorithm-guide|vidIQ guide]] (19:05-20:25). Cheap, free, and testable on any channel.

1. In YouTube Studio, open Content in advanced mode and pull the last 20 videos.
2. Make four columns: title, CTR, average view duration, views in the first 7 days.
3. The average of each number column is your baseline: "the exact bar the algorithm has set for you".
4. Find the 2-3 videos that beat the baseline on every number at once. High views with low CTR probably means an outside push (Reddit, a newsletter).
5. Ask what differed: topic, title structure, thumbnail, the first 30 seconds. Repeat it on purpose. Do not chase the all-time top video; chase the best relative to baseline.
6. Add a second sheet with a weekly screenshot of traffic sources ([[wiki/concepts/youtube-traffic-sources-browse-suggested-search|browse, suggested, search]]).

**Caveat:** the "baseline decides expansion" mechanism behind this is creator-inferred ([[wiki/concepts/youtube-channel-baseline-and-explore-exploit|see the grading]]). The exercise is useful either way, because it finds your own winning pattern. On a low-volume channel, 20 videos is not 20 solid data points if each gets under about 1,000 impressions; read CTR with that noise in mind.
