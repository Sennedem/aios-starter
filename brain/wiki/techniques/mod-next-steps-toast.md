# Mod: Next steps

**What it does.** At the end of every turn, a small element in the chat UI offers about three recommended next actions, or a dismiss. Built by Thoric, a Claude Code engineer, who uses it a lot (creator-claimed) [00:34-00:40]. Source: [[wiki/sources/nateherk-claude-code-mods|Nate Herk, Claude Code mods]].

## What Nate showed

After he asked "what action items do I have for ClickUp today?", the popup offered: close demo and old hackathon tasks, push certification due dates to next week, run the morning coffee briefing, or dismiss [00:51-01:01].

## Setup

Copy the mod's page or link, give it to Claude and say "set up this mod". It appears in the same chat in about 30 seconds [01:43-01:55]. Under the hood it is a plugin installed through Claude Code's plugin command (see [[wiki/concepts/claude-code-mods|mods]]).

## Nate's own verdict

He is unsure it helps when you steer your own day doing knowledge work, and thinks it is likely useful when building an app ("fix this bug first", "merge these changes") [01:02-01:20]. Creator opinion, no measurement.
