# TikTok pre-post checklist

A checklist distilled from [[wiki/sources/robertbenjamin-tiktok-algorithm-2026|Robert Benjamin]]. Each line carries its grade, so a failed run teaches you which claim to drop. Run it top to bottom before posting; none of it costs money.

1. **Comparables.** Search the topic. Pick 2-3 high-view videos in the format you plan (skit, tutorial). Write down format and length. *(Creator-empirical; a format sanity check, not a target in seconds.)* See [[wiki/concepts/tiktok-length-and-format-matching]].
2. **Trend fit.** Is the topic or format circulating in your niche right now? If not, say why you are posting it anyway. *(Creator-empirical.)*
3. **Hook.** One line of on-screen text in the first seconds, containing the topic keyword. Colour is optional: red is his habit, not a result. *(Folklore for colour.)*
4. **Pacing.** Change what is on screen every few seconds; no static stretch. *(Corroborated by retention logic.)* See [[wiki/concepts/shorts-retention-vvsa-avd]].
5. **Keywords agree.** The same topic words in the hook, the description, and a CTA that makes viewers type the keyword in the comments. *(Partly official, partly inference.)* See [[wiki/concepts/tiktok-keyword-signal-stack]].
6. **Hashtags.** Three, specific, on topic. No #fyp. *(Preference; consistent with academic findings that hashtag piling does not help.)*
7. **Account.** Niche word in the display name, playlists per sub-topic, a bio with keywords. One-off setup. *(Creator-empirical, one case.)* See [[wiki/concepts/tiktok-account-niche-signals]].
8. **Engagement habit.** Comment, watch and reply in your niche 3-5 days a week at irregular times, and reply to comments on your own posts. *(Folklore as a ranking lever; harmless.)* See [[wiki/concepts/tiktok-bot-suspicion-and-shadowban-lore]].
9. **Review.** After 48 hours, check completion and views against the comparables from step 1, using the logic in [[wiki/techniques/diagnosing-a-flatlined-short]] as a model (those are YouTube bands; TikTok has no public band table).

**Test design if you try it:** change one thing per batch (for example keyword alignment), post 5 or more videos, and compare against the previous batch. One viral post proves nothing either way.
