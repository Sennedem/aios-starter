# TikTok keyword signal stack

**Claim (creator-empirical, partly official):** TikTok reads the same topic words from several places on a post. When the words agree across all of them, the video is classified clearly and shown to the right people. His stack:

1. The on-screen hook text carries the keyword.
2. The description repeats the same words.
3. Exactly three hashtags: on topic, specific ("isolated to exactly what I'm talking about"), not broad.
4. Comments echo the keyword, driven by a "comment [WORD]" CTA inside the video, so commenters type the keyword for you.

Source: [[wiki/sources/robertbenjamin-tiktok-algorithm-2026|Robert Benjamin]] (08:26-09:15).

## Grade by layer

| Layer | Grade |
|---|---|
| Captions, hashtags and sounds as inputs | **Official** (TikTok's recommendations post lists "video information: captions, sounds, hashtags") |
| Three hashtags rather than another number | **Creator preference**, not shown |
| Comments echoing the keyword boosting reach | **Inference.** Comment count is an official interaction signal; the keyword-match part is not |
| Alignment across all four | **Plausible**, untested. A single creator's observation |

## Why the CTA-comment trick is worth separating

It does two things at once: it raises comment count (an engagement signal on its face) and it seeds the keyword. Only the first has any support. TikTok also says spam content is not recommended, so an extreme "comment X for the link" loop carries policy risk for a brand, the same trade-off the dmscales source flags for spammy CTAs on YouTube ([[wiki/concepts/shorts-retention-vvsa-avd]]).

It is one step of the [[wiki/techniques/tiktok-pre-post-checklist|TikTok pre-post checklist]].
