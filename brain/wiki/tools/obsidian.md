# Obsidian

A free note app that opens a folder of markdown files as a vault. It follows `[[wikilinks]]`, shows backlinks and draws the graph view.

## How it is used here

- The vault is the `brain/` folder. Open it with "Open folder as vault".
- Claude writes the pages. Obsidian is where you read, search and browse them.
- Graph view (Ctrl/Cmd+G) shows each project and the wiki as separate clusters, coloured by folder.
- The files stay plain markdown on your disk, so any other tool or model can read them too.
