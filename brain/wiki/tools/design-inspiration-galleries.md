# Design inspiration galleries (godly.website, Awwwards, Motion Sites)

Three site-level inspiration sources Nate Herk names alongside [[wiki/tools/21st-dev|21st.dev]] when briefing a one-shot website prompt in [[wiki/sources/nateherk-fable-5-1-kills-website-slop|"Fable 5.1 kills website slop"]]. They share one page because none gets more than a passing mention on its own.

## godly.website (godly.design)

A gallery of trending site designs, browsable by element type (hero sections, logos, CTAs, footers, OG images) and by category (technology, e-commerce, restaurant, fashion). The category filter matters for the same reason as [[wiki/concepts/three-ps-pain-person-promise|the three P's]]: "your site probably is going to convert better if it feels like it's in your niche talking to your avatar."

## Awwwards

A gallery of award-winning site designs, also browsable by category. Used the same way as godly.website, to settle "what kind of feel do you want."

## Motion Sites

A library of pre-built animated backgrounds ("jaw-dropping animated backgrounds") that you drop into a new site instead of generating one from scratch. Nate used one as the starting point for his personal site's background, then made it interactive on top of the base animation.

## How to use them

Gather a small set of real references at the whole-page level before any frontend code gets written, and name them in the prompt. For individual components, use [[wiki/tools/21st-dev|21st.dev]]. The full method is [[wiki/techniques/inspiration-driven-site-prompting|inspiration-driven site prompting]].
