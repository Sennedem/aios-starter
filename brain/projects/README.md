# Projects

One folder per business, job, course or big project. Each folder has a `CONTEXT.md` that Claude reads before it does any work on that project, and updates when the work changes something.

`/setup` creates the first ones from your answers. To add one later, say "new project: <name>" and Claude copies `templates/project-context.md` into `projects/<slug>/CONTEXT.md` and adds a line here and in the brain [[README]].
